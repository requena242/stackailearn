# Checklist — Stack AI in 14 days

One block a day. If a day slips, do not “catch up” three: do today’s.

## Day 1 — Account and workspace

- [ ] Cursor installed, one workspace, not ten clones
- [ ] Grok Bot with the charter (draft only)
- [ ] Site repo (or folder) open in Cursor

## Day 2 — What to publish first

- [ ] A list of 3 URLs, not 30
- [ ] The first one is a profile or tutorial you already know how to use
- [ ] Slugs written down

## Day 3 — Profile

- [ ] Tool template filled (ES + EN)
- [ ] One real con
- [ ] No invented affiliate

## Day 4 — Tutorial

- [ ] Tutorial template filled
- [ ] Steps include “what you should see”
- [ ] Link to the profile

## Day 5 — Comparison

- [ ] One question, two tools
- [ ] A usable verdict
- [ ] Links to both profiles

## Day 6 — Cursor prompts

- [ ] Prompts 1–6 copied into a note
- [ ] One real change made with the “only this” prompt

## Day 7 — Grok Bot charter

- [ ] Charter pasted into the bot
- [ ] A draft, not a merge

## Day 8 — Affiliates

- [ ] List: real program / no program
- [ ] Only a real URL gets pasted
- [ ] Site disclosure left intact

## Day 9 — Newsletter

- [ ] One lead magnet (a short list), not a course
- [ ] Form with a real provider, or an honest “ID missing” note

## Day 10 — SEO for one URL

- [ ] Title, description, H1 aligned
- [ ] 2 internal links
- [ ] Canonical / locale correct (`/es/…` or `/en/…`)

## Day 11 — Distribution

- [ ] One X post with a finding, not “read my site”
- [ ] Pinterest only if you have a real image and ≥15 published URLs (otherwise wait)

## Day 12 — Quality

- [ ] Navigation 404s: none
- [ ] Copy in both languages
- [ ] Ads still off if impressions are not stable

## Day 13 — Sales page

- [ ] Promise, who it is not for, FAQ
- [ ] Price visible
- [ ] Checkout or preview through to thanks

## Day 14 — 30-minute routine

- [ ] A fixed block (calendar)
- [ ] One URL or one step, not “the whole site”
- [ ] The bot does not publish alone

When day 14 is done: go back to day 2 with another 3 URLs.
