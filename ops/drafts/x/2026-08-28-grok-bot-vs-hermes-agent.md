## Hilo (ES)

1/ Grok Bot y Hermes Agent no resuelven el mismo trabajo.

Uno es un teammate con ordenador en la nube. El otro es un agente CLI en tu máquina.

2/ Grok Bot no es grok.com.

No es el chat de X. Es un compañero con nombre, memoria y un Agent Computer: navegador, archivos, terminal remotos.

3/ Elige Grok Bot si el entregable acaba en apps reales.

Mail, un doc, un panel web. Varios bots comparten la máquina. Tú entras cuando pide login (2FA, CAPTCHA).

4/ Elige Hermes si vives en la terminal.

Software libre de Nous Research. Pagas el proveedor del modelo o corres local. Gateway a Telegram/Slack cuando el chat ya funciona.

5/ Hermes en local no abre Google Docs por ti.

Grok Bot no vive en tu repo ni en tu shell.

6/ Sin oficio claro, Grok Bot improvisa y ensucia la máquina compartida.

Con Hermes, montar gateway o cron antes de que el chat responda es la forma clásica de romperlo.

7/ No es «gratis vs de pago».

Es «¿quieres un teammate en la nube o un agente en tu box?».

## Standalone (EN)

Grok Bot is not grok.com. It is a named teammate with a cloud computer for work that ends in real web apps.

Hermes Agent is a free CLI on your machine. You pay the model. Gateway comes later.
