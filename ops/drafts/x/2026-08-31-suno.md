## Standalone (ES)

Suno genera una canción completa — letra, voz e instrumentación — a partir de un prompt de una línea. No es TTS ni vídeo: si necesitas locución, usa ElevenLabs; si necesitas motion, usa Runway. El flujo que no quema créditos: género + tempo + tema en una frase → Create → escuchar las dos versiones → elegir la que encaje. Si la letra suena genérica, reescribe el prompt antes de regenerar diez veces.

El plan gratuito da unas 10 canciones al día para probar; para publicar en YouTube o anuncios necesitas Pro o Premier. Descarga el MP3 y reprodúcelo sobre tu clip para comprobar si el ritmo encaja.
