## Day 3 — Profile (extract)

**Tagline:** An editor where the agent edits the repo; you review the diff.

**Not for:** Anyone who wants a chat and to paste code by hand. That is ChatGPT.

**A real con:** If you do not scope the file or the change, it rewrites things you did not ask for.

**A fake con (bin it):** «AI is sometimes wrong.»

**Quick tutorial (idea):** Open Composer → paste «Do ONLY this: …» → review a one-file diff → apply or revert.

**Affiliate:** If there is no real program URL, the button goes official. Do not invent one.

## Day 4 — Tutorial (extract)

**Title:** How to lock Cursor to a single file (15 min)

**Problem:** You asked it to «fix the hero» and it changed three components.

**Step 1:** Open Composer / Agent in the right repo.
**What you should see:** The chat — not a grok.com tab.

**Step 2:** Write: `Do ONLY this: change the H1 in [path]. Touch no other files.`
**What you should see:** A one-file diff. If there are more files, do not accept.

**Common miss:** «Improve the home» with no path. The model picks the scope.

**Internal link:** `cursor` profile. If it is not there, this tutorial does not ship.

## Day 5 — Comparison (extract)

**Question:** Who helps me change code in a repo that already exists?

**Criteria (same sitting, not memory):**
- The change lands in a diff you can revert
- Whether you must copy/paste into another editor
- Price of the flow (the minimum plan you used today)
- Where it breaks (context, extra files, invented paths)

**Choose Cursor if** the work is the repo.
**Choose ChatGPT if** you only need a snippet to paste.

**Verdict:** To touch the repo, Cursor. For a loose snippet, ChatGPT. Do not pay for both the first month.

**Do not publish if** you did not open both tools the same afternoon.
