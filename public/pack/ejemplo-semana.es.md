## Día 3 — Ficha (extracto)

**Tagline:** Un editor donde el agente edita el repo; tú revisas el diff.

**Para quién no:** Quien quiere un chat y pegar código a mano. Eso es ChatGPT.

**Contra que sí:** Si no acotas el archivo o el cambio, reescribe cosas que no pediste.

**Contra que no (tíralo):** «La IA a veces se equivoca.»

**Tutorial rápido (idea):** Abrir Composer → pegar «Haz SOLO esto: …» → revisar un diff de un archivo → apply o revert.

**Afiliado:** Si no hay URL real de programa, botón al sitio oficial. Sin inventar.

## Día 4 — Tutorial (extracto)

**Título:** Cómo limitar a Cursor a un solo archivo (15 min)

**Problema:** Pediste «arregla el hero» y te cambió tres componentes.

**Paso 1:** Abre Composer / Agent en el repo correcto.
**Qué debes ver:** El chat, no una pestaña de grok.com.

**Paso 2:** Escribe: `Haz SOLO esto: cambia el H1 de [ruta]. No toques más archivos.`
**Qué debes ver:** Un diff de un archivo. Si hay más, no aceptes.

**Error habitual:** «Mejora la home» sin ruta. El modelo elige el alcance.

**Enlace interno:** ficha `cursor`. Si no está, este tutorial no se publica.

## Día 5 — Comparativa (extracto)

**Pregunta:** ¿Quién me ayuda a cambiar código de un repo que ya existe?

**Criterios (sesión real, no memoria):**
- El cambio queda en un diff que puedes revertir
- Hace falta o no copiar/pegar a otro editor
- Precio del flujo (plan mínimo que usaste hoy)
- Dónde se rompe (contexto, archivos de más, alucinación de rutas)

**Elige Cursor si** el trabajo es el repo.
**Elige ChatGPT si** solo necesitas un snippet para pegar.

**Veredicto:** Para tocar el repo, Cursor. Para un fragmento suelto, ChatGPT. No pagues los dos el primer mes.

**No publiques si** no abriste las dos herramientas en la misma tarde.
